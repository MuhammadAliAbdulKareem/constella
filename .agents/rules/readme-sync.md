# Always Maintain and Update README.md

Whenever any architectural, structural, feature, or functional updates are made to the project:
1. **Update `README.md` immediately**: Keep the project directory tree, feature list, instructions, shortcuts, and deployment notes 100% accurate and aligned with the current state of the codebase.
2. **Preserve Documentation Clarity**: Use clear Arabic/English documentation with diagrams, tables, and step-by-step guides so that any instructor or student can easily follow and use the portal.
