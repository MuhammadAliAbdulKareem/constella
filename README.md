# موقع السكاشن

موقع ثابت (static) من غير سيرفر ولا قاعدة بيانات. كل سكشن هو ملف HTML واحد.

## الملفات
```
index.html      الصفحة الرئيسية (متعدلش فيها)
courses.js      الملف الوحيد اللي بتعدّل فيه
decks/          الـ decks بتاعتك، فولدر لكل كورس
back-to-library.snippet.html   سطر بترجّع الطالب للموقع من جوّه أي deck
```

## اللي جوّه الموقع
- سما حيّة: نجوم بتلمع، شهاب بيعدّي كل شوية، ولما تحرّك الماوس النجوم القريبة بتتوصّل ببعض.
- كل كورس كوكبة بتترسم لما توصل لها بالسكرول، وفيه مذنّب بيمشي عليها لحد أحدث سكشن.
- لما الطالب يفتح سكشن بيحصل "warp jump" قبل ما الـ deck يفتح.
- حلقة تقدّم لكل كورس: الخارجية للسكاشن المنشورة، والداخلية للي الطالب فتحه.
- الحركات كلها بتتوقف تلقائيًا لو الجهاز عامل reduce motion.

## تجربة على جهازك (مهم)
**متفتحش `index.html` بدبل كليك.** كروم بيمنع خطوط وحركات كتير لما تفتح ملف مباشر من غير سيرفر، فهتحس إن الموقع "ميت" وده مش شكله الحقيقي.

بدل كده:
- **ويندوز:** دبل كليك على `Start Site.bat` (معتمدش على تثبيت Python، بيستخدم PowerShell الجاهز في كل ويندوز). لو ظهرت رسالة أمان (SmartScreen)، دوس "More info" ثم "Run anyway".
- **ماك:** دبل كليك على `Start Site.command` (أول مرة: كليك يمين ← Open). محتاج Python 3 متثبت (موجود افتراضيًا في أغلب أجهزة الماك).

هيفتحلك المتصفح على `http://localhost:8000` تلقائيًا، وهنا كل الحركات هتشتغل صح. سيب الشباك (نافذة PowerShell أو Terminal) شغال لحد ما تخلص تجربة، وقفله بعدين علشان توقف السيرفر.

الطلاب مش هيحتاجوا الخطوة دي؛ المشكلة دي بتظهر بس وانت بتجرب على جهازك بملف مفتوح مباشر. أول ما ترفع الموقع أونلاين (GitHub Pages/Netlify) هيشتغل عادي من غير أي إعداد.

## كل أسبوع (دقيقة واحدة)
1. حط ملف السكشن في `decks/<course>/week-XX.html`.
2. في `courses.js` انسخ سطر `week` وعدّل: الرقم، العنوان، المواضيع، مسار الملف، التاريخ.
3. ارفع التغيير. النجمة بتنوّر لوحدها والسكشن ده بيبقى "Latest session".

## كورس جديد
انسخ بلوك الكورس كله في `courses.js` وغيّر `id` و `title` و `hue` و `totalWeeks` (الترم 10 سكاشن).

## زرار الرجوع داخل الـ deck
الصق محتوى `back-to-library.snippet.html` في كل deck بعد `<body>`.

## النشر على GitHub Pages (مجاني)
1. اعمل حساب على github.com وأنشئ Repository جديد (Public)، مثلًا `sessions`.
2. Add file ثم Upload files، اسحب كل محتويات الفولدر ده (مش الفولدر نفسه)، وCommit.
3. Settings ثم Pages، اختار Source: Deploy from a branch، Branch: `main` و Folder: `/ (root)`، وSave.
4. بعد دقيقة الموقع يبقى على `https://USERNAME.github.io/sessions/`. ابعت اللينك للطلاب.

بدائل: Netlify أو Cloudflare Pages. اسحب الفولدر على netlify.com/drop وخلاص.

## ملاحظات
- تقدّم الطالب ("Opened") بيتحفظ في متصفحه هو بس.
- البيانات اللي في `courses.js` حاليًا أمثلة. عدّلها بتاعتك.
- الـ decks لازم تبقى نفس أسماء الملفات اللي في `courses.js`.
