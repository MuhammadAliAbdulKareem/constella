# Constella — Interactive Course Sessions Portal

بوابة تفاعلية ذكية للسكاشن الجامعية وعروض السلايدات التفاعلية (PWA & Offline Capable)، من إعداد **م. محمد علي عبد الكريم** (كلية تكنولوجيا المعلومات وعلوم الحاسب — جامعة سيناء).

---

## 📁 هيكلية المشروع المعمارية (Project Architecture)

المشروع مبني بهيكلية معيارية تفصل بدقة بين **الأصول (Assets)**، **البيانات (Data)**، **السكاشن (Decks)**، و**أدوات التشغيل (Scripts)**:

```text
course-site/
├── index.html                   # صفحة الدخول الرئيسية للبوابة ومحرك الكوكبات
├── manifest.json                # إعدادات تثبيت تطبيق الـ PWA
├── sw.js                        # محرك التخزين المؤقت والعمل دون إنترنت (PWA Service Worker)
├── firebase.json                # إعدادات الاستضافة وCache-Control
├── Start Site.bat               # تشغيل السيرفر المحلي بنقرة واحدة (1-Click Local Server)
├── README.md                    # دليل المشروع والتوثيق الشامل
│
├── assets/                      # كافة الأصول الثابتة مصنفة حسب النوع
│   ├── css/
│   │   └── app.css              # ملف التصميم والأنظمة اللونية (Dark & Light tokens)
│   ├── js/
│   │   └── app.js               # محرك الكوكبات السماوية، البحث، والـ PWA Engine
│   └── icons/                   # كافة أيقونات وتطبيقات الموقع (PWA Icons & Favicon)
│       ├── favicon.svg          # أيقونة المتصفح المتجهة (Vector SVG)
│       ├── apple-touch-icon.png # أيقونة أجهزة Apple و iOS
│       ├── icon-192.png         # أيقونة التطبيق بدقة 192px
│       ├── icon-512.png         # أيقونة التطبيق بدقة 512px
│       └── icon-maskable-512.png# أيقونة متوافقة مع قوالب أندرويد المتكيفة
│
├── data/                        # فصل بيانات السكاشن عن منطق الكود
│   └── courses.js               # ملف بيانات الكورسات والسكاشن (الوحيد المُعدَّل أسبوعياً)
│
├── scripts/                     # سكريبتات وأدوات التشغيل المحلية
│   └── Start-Site.ps1           # سكريبت السيرفر المحلي الخفيف (PowerShell HTTP Listener)
│
└── decks/                       # مجلد سلايدات وجلسات الكورسات
    ├── templates/               # القوالب المعيارية للسكاشن
    │   └── template-session.html# قالب جاهز لإنشاء أي سكشن جديد بسهولة
    ├── data-structures/         # كورس هياكل البيانات (C++)
    │   ├── Week ⇔ 01/           # Session 01 + Functions_Memory.cpp
    │   ├── Week ⇔ 02/           # Session 02 + Complexity_BigO.cpp
    │   └── Week ⇔ 03/           # Session 03 + ArrayList.cpp
    └── multimedia/              # كورس الوسائط المتعددة (Python)
        ├── Week ⇔ 01/           # Session 01 + session01_fundamentals.py
        ├── Week ⇔ 02/           # Session 02 + session02_oop.py
        └── Week ⇔ 03/           # Session 03 + session03_digital_sound.py
```

## ✨ المميزات والقدرات الأساسية

- **نظام ثيم موحد وشامل (Unified Theming):** تبديل سلس ولحظي بين الوضع الداكن والوضع الفاتح (`Dark` / `Light`) في البوابة الرئيسية وكافة السكاشن، مع مزامنة فورية عبر كافة النوافذ والتبويبات المفتوحة بدون أي وميض (`Zero-FOUC`).
- **محرك الكوكبات السماوية (Cosmic Starfield & Constellations):** رسم تفاعلي لمسار الجلسات كنجوم وكواكب تتصل ببعضها مع مؤشرات تقدم ذكية وحساب لنسبة إنجاز الطالب.
- **عروض تفاعلية متجاوبة (Edge-to-Edge Adaptive Decks):** السلايدات تتناسب تلقائياً مع كافة مقاسات الشاشات والهواتف الذكية مع دعم السحب وإيماءات اللمس ولوحة المفاتيح.
- **دعم كامل للعمل بدون إنترنت (Offline PWA):** إمكانية تثبيت البوابة كتطبيق مستقل على أجهزة Windows, macOS, Android, و iOS مع كاش ذكي `Network-First` للأكواد و `Cache-First` للخطوط والصور.

## ⚡ بيئات البرمجة السحابية المدمجة (Interactive Compilers)

تم دمج بيئات سحابية مباشرة في ترويسة كل سكشن وبجانب كل نافذة كود برمجي:

| الكورس | البيئة السحابية | المميزات وطريقة العمل |
| :--- | :--- | :--- |
| **Multimedia (Python)** | **Google Colab** (`⚡ Google Colab ↗`) | تشغيل فوري بنقرة واحدة داخل بيئة نوتبوك تفاعلية على Google Colab تدعم مكتبات الصوت والرسوميات، مع زر نسخ الكود وفتح المفكرة مباشرة. |
| **Data Structures (C++)** | **Online C++** (`⚡ Online C++ ↗`) | مترجم C++ فوري وسريع (Online-CPP) لتجربة الـ Pointers، الذاكرة، والخوارزميات على الهاتف أو اللابتوب دون الحاجة لتثبيت بيئات تطوير محلية. |

## 🎮 أدوات الشرح التفاعلية واختصارات لوحة المفاتيح (Deck Hotkeys)

تحتوي عروض الشرائح على أدوات متقدمة لتسهيل الشرح والعرض أثناء المحاضرات والسكاشن:

| الزر / الاختصار | الوظيفة | الوصف |
| :---: | :--- | :--- |
| `B` | **وضع السبورة السوداء (Blackboard Mode)** | تحويل الشاشة فورياً إلى سبورة مظلمة نقية للتركيز والشرح الحر أثناء السكشن. |
| `G` أو `O` | **درج الفهرس السريع (Slide Drawer)** | فتح درج جانبي يعرض كافة عناوين الشرائح مع أرقامها للتنقل الفوري بين الموضوعات (يمكن فتحه أيضاً بالنقر على عداد الشرائح السفلي). |
| `P` | **قلم الشرح التفاعلي (Drawing Pen)** | تفعيل لوحة رسم حرة فوق الشرائح بالقلم الليزري لكتابة الملاحظات ورسم المخططات. |
| `F` | **ملء الشاشة (Fullscreen)** | تفعيل وضع العرض الكامل للبروجيكتور وإخفاء هوامش المتصفح. |
| `T` | **تبديل الثيم (Theme Toggle)** | التبديل بين الوضع المظلم والفاتح. |
| `→` / `Space` | **الشريحة التالية** | الانتقال للأمام (يدعم السحب لليسار على شاشات اللمس). |
| `←` | **الشريحة السابقة** | الرجوع للخلف (يدعم السحب لليمين على شاشات اللمس). |
| `?` | **دليل الاختصارات (Shortcuts Modal)** | إظهار نافذة مساعدة سريعة تضم كافة الاختصارات. |

## 🚀 تجربة الموقع محلياً على جهازك

* **على نظام Windows:**
  اضغط مرتين على ملف **`Start Site.bat`** في مجلد المشروع الرئيسي.
  * سيقوم بتشغيل سيرفر محلي خفيف جداً عبر PowerShell ويفتح المتصفح تلقائياً على الرابط: `http://localhost:8000`.
  * تضمن هذه الطريقة تشغيل كامل ملفات الـ PWA، والخطوط، والـ Audio Synthesis دون أي قيود أمان للمتصفحات.

## ⚡ إضافة سكشن جديد (دقيقة واحدة)

1. انسخ ملف **`decks/templates/template-session.html`** إلى مجلد الكورس المطلوب (مثلاً: `decks/multimedia/Week ⇔ 04/Session ⇔ 04.html`).
2. افتح ملف **`data/courses.js`**، وانسخ كائن أسبوع جديد (`week`) داخل مصفوفة `weeks` الخاصة بالكورس:
   ```javascript
   {
     week: 4,
     title: "Session Title Here",
     titleAr: "عنوان السكشن بالعربي",
     topics: ["topic 1", "topic 2", "topic 3"],
     keywordsAr: ["كلمات", "مفتاحية", "للبحث"],
     file: "decks/multimedia/Week ⇔ 04/Session ⇔ 04.html",
     codeFile: "decks/multimedia/Week ⇔ 04/session04_example.py",
     codeName: "session04_example.py",
     date: "2026-10-13",
     duration: "75 min",
     slides: 20
   }
   ```
3. احفظ الملف، وستظهر النجمة الجديدة في مسار الكوكبة تلقائياً كأحدث سكشن (`Latest session`).
